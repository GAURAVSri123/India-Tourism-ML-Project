## Methodology note
Monthly forecasting uses 72 national observations from Jan 2019 to Dec 2024. Country clustering uses Q1–Q4 percentage shares only for 183 profiles after a 100-arrival minimum-volume filter. Annual arrivals are not clustering features. The broad official source did not provide a complete monthly-by-country matrix; quarterly shares are therefore a proxy and are labelled as such.
